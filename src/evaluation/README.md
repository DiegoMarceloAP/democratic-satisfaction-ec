# src/evaluation/

Fase de Evaluación (CRISP-DM): valida el desempeño de los 4 modelos con Time Series Split, arma la tabla comparativa final, aplica la prueba estadística formal (Friedman + Wilcoxon) sobre esa comparación, y explica las predicciones con el marco SHAP dual (global y local).

-  `time_series_split.py`: partición de validación cruzada temporal (ventana expansiva) sobre los años reales de encuesta de Latinobarómetro, dejando siempre años más recientes como prueba. Incluye `reportar_balance_por_fold` para verificar el balance de clases de cada fold antes de aplicar SMOTE.

-  `metricas.py`: carga los `reports/tablas/resultados_<modelo>.csv` (uno por fold, generados por cada `src/models/*.py`), promedia entre folds (media + desviación estándar, para ver qué tan estable es cada modelo entre años) y arma la tabla comparativa final -- Accuracy, F1 (Macro/Weighted), F1 de "Satisfecho", PR-AUC y tiempo de entrenamiento -- ordenada por PR-AUC (métrica reina). Tolera que falte algún modelo (avisa y compara con los disponibles). Guarda `reports/tablas/tabla_comparativa_final.csv` y gráficos de barras con barras de error en `reports/figures/`.

-  `pruebas_estadisticas.py`: prueba formal (Friedman + Wilcoxon con corrección de Holm-Bonferroni) sobre la comparación de la tabla anterior, para no basar la conclusión solo en la inspección visual de las barras de error. Toma los valores por fold de cada modelo desde los mismos CSV que usa `metricas.py`, ordenados por año para que la prueba pareada compare siempre el mismo fold entre modelos. Guarda `reports/tablas/resultados_estadisticos.csv`.

-  `shap_explicabilidad.py`: marco XAI dual -- TreeSHAP (`shap.TreeExplainer`) para XGBoost/LightGBM, KernelSHAP (`shap.KernelExplainer`) para CNN-LSTM/TabNet. Reconstruye el X_test EXACTO de cada fold (misma imputación/SMOTE/codificación que cada script de entrenamiento) para explicar siempre encuestados reales, nunca filas sintéticas de SMOTE. Calcula SHAP fold por fold (no un pool global), para poder comparar qué variables cambian entre años en vez de esconder esa heterogeneidad en un promedio. Para CNN-LSTM, la ventana temporal se aplana en columnas `seq_t{t}_{variable}`/`mask_t{t}` (misma convención que el aplanado de SMOTE de `cnn_lstm.py`), reutilizando la idea de `rezagos_macro.py`. Incluye `explicar_perfil_local` para la auditoría de un encuestado puntual (marco XAI local, complementario al resumen global).
